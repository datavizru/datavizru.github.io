# Инструкция по загрузке данных и экспорту простых визуализаций

Эта инструкция написана для сайта «Визуализируй свои данные». Он работает как браузерный редактор диаграмм: вы загружаете CSV, выбираете тип графика, сопоставляете столбцы с осями и сериями, настраиваете оформление и экспортируете результат в `PNG` или `SVG`.

Данные никуда не отправляются: CSV читается прямо в браузере. Для работы нужен компьютер или ноутбук. На телефоне сайт показывает только ознакомительный экран, а сам редактор рассчитан на широкий экран.

## 1. Что лежит в папке задания

В каждом задании из папки `Tasks/Level 1` обычно есть два файла:

- `technical_brief.docx` — краткое описание задания и ожидаемого смысла визуализации.
- `data.csv` — таблица с данными, которую нужно загрузить на сайт.

Пример:

```text
Tasks/
  Level 1/
    01 Круассаны для будильников/
      technical_brief.docx
      data.csv
```

Начинайте с `technical_brief.docx`: он объясняет, что именно надо показать. Потом открывайте `data.csv` в редакторе диаграмм.

## 2. Как открыть редактор

Откройте сайт:

```text
https://datavizru.github.io/
```

Если вы работаете с локальной копией проекта, откройте `index.html` в браузере или запустите локальный сервер. В обычной учебной работе достаточно открыть опубликованный сайт.

В правом верхнем углу есть переключатель языка `ENG / RUS`. Для этой инструкции удобнее выбрать `RUS`.

## 3. Как устроен интерфейс

Редактор состоит из трех основных зон.

Левая панель:

- `Тип диаграммы` — выбор вида графика.
- `Данные` — выбор примера, загрузка CSV и сопоставление столбцов.
- `Текст` — заголовок, подзаголовок, названия осей, комментарий и источники.
- `Экспорт` — сохранение готовой визуализации в `PNG 2×`, `PNG 4×` или `SVG`.
- `Проект` — сохранение и загрузка проекта в формате `.json`.

Центр экрана:

- предпросмотр визуализации;
- масштабирование кнопками `−`, `+` и `⟲`;
- перемещение холста при зажатом пробеле или средней кнопке мыши.

Правая панель:

- шаблоны оформления;
- размер файла;
- поля и отступы;
- шрифты и цвета;
- оси;
- подписи значений;
- легенда;
- специальные настройки для некоторых типов графиков.

## 4. Как загрузить CSV

1. Откройте папку своего задания.
2. Найдите файл `data.csv`.
3. На сайте откройте блок `Данные` на левой панели.
4. В блоке `Файл CSV` проверьте настройки:
   - `Разделитель полей` — обычно `Запятая (,)`;
   - `Дес. разделитель` — обычно `Точка (1.25)`.
5. Нажмите `Загрузить CSV…`.
6. Выберите файл `data.csv`.
7. Проверьте строку под кнопкой загрузки: сайт должен показать имя файла, количество строк, разделитель и десятичный разделитель.

Если после загрузки график выглядит странно, сначала проверьте настройки разделителя. В заданиях из папки `Tasks` используется CSV с запятыми между столбцами и кодировкой UTF-8.

## 5. Как понять, какие столбцы куда ставить

После загрузки CSV в блоке `Данные` появятся выпадающие списки:

- `Ось X / категория`;
- `Ось Y / значение`;
- `Ряд / серия (цвет)`;
- для точечной диаграммы также может использоваться `Подпись точки (имя)`.

Главное правило:

- текстовый столбец чаще всего идет в `Ось X / категория`;
- числовой столбец идет в `Ось Y / значение`;
- дополнительный текстовый столбец, если он есть, идет в `Ряд / серия (цвет)`.

Пример таблицы из двух столбцов:

```text
День,Круассаны
Понедельник,12
Вторник,17
Среда,15
```

Настройка:

- `Ось X / категория` — `День`;
- `Ось Y / значение` — `Круассаны`;
- `Ряд / серия (цвет)` — `— нет —`.

Пример таблицы из трех столбцов:

```text
Этап,Статья,Расходы
Подготовка,Чай,12
Подготовка,Карты,8
Выезд,Чай,18
```

Настройка:

- `Ось X / категория` — `Этап`;
- `Ось Y / значение` — `Расходы`;
- `Ряд / серия (цвет)` — `Статья`.

## 6. Какие типы диаграмм есть на сайте

В блоке `Тип диаграммы` доступны такие варианты:

- `Столбчатая`;
- `Столбчатая с накоплением`;
- `Столбчатая нормированая`;
- `Линейчатая`;
- `Линейчатая с накоплением`;
- `Линейчатая нормированая`;
- `Леденцовая горизонтальная`;
- `Леденцовая вертикальная`;
- `Линейный график`;
- `Ступенчатый график`;
- `Площадная`;
- `Точечная`;
- `Тепловая карта`.

Для первых заданий чаще всего достаточно столбчатой, линейчатой, линейной, накопительной столбчатой и тепловой карты.

## 7. Как выбрать простой тип визуализации

Перед выбором спросите себя: что нужно показать — сравнение, изменение, состав или связь?

| Данные | Что выбрать |
| --- | --- |
| Категория + число | `Столбчатая` или `Линейчатая` |
| Время + число | `Линейный график` |
| Категория + группа + число | `Столбчатая с накоплением` или обычная `Столбчатая` с сериями |
| Части общего итога по группам | `Столбчатая с накоплением` |
| Две категории + число | `Тепловая карта` |
| X + Y для точек | `Точечная` |

### Столбчатая

Используйте для сравнения категорий: отделы, комнаты, цвета, залы, дисциплины.

Настройка:

- категория — в `Ось X / категория`;
- число — в `Ось Y / значение`;
- если категорий много или подписи длинные, попробуйте `Линейчатая`.

### Линейчатая

Это горизонтальная версия столбчатой диаграммы. Она удобна, когда названия категорий длинные.

Настройка такая же:

- категория — в `Ось X / категория`;
- число — в `Ось Y / значение`.

### Линейный график

Используйте, если первый столбец показывает время или порядок: день, неделя, месяц, квартал, час.

Важно: не сортируйте дни и месяцы по алфавиту. Сохраняйте естественный порядок.

### Столбчатая с накоплением

Используйте для таблицы из трех столбцов, когда нужно показать состав каждой категории.

Пример:

- `Квартал` — категория;
- `Тип обещания` — серия;
- `Обещания` — значение.

На графике каждый столбец будет состоять из цветных частей.

### Столбчатая нормированая

Используйте, когда важны не абсолютные числа, а доли внутри каждой категории. Каждый столбец приводится к 100%.

### Тепловая карта

Используйте для таблицы из трех столбцов, если нужно сравнить значения на пересечении двух категорий.

Пример:

- `Месяц`;
- `Ковер`;
- `Метры`.

Одна категория идет по горизонтали, другая — по вертикали, а число превращается в цвет ячейки.

## 8. Как оформить график

После загрузки данных и выбора типа графика заполните блок `Текст`.

Минимально нужно настроить:

- `Заголовок` — что показывает график;
- `Подзаголовок` — уточнение, период или единицы измерения;
- `Заголовок оси X`;
- `Заголовок оси Y`;
- `Футер · источники` — откуда данные, если это требуется в задании.

На правой панели можно настроить внешний вид:

- `Шаблон оформления` — быстрый старт для стиля;
- `Размер` — ширина и высота итогового файла в пикселях;
- `Надписи` — шрифты, размеры и цвета текста;
- `Ось X` и `Ось Y` — линии, сетка, подписи, диапазон значений;
- `Заливка и палитра` — цвет элементов и цвета серий;
- `Подписи значений` — числа прямо на графике;
- `Отображение` — легенда и маркеры легенды.

Не нужно менять все настройки сразу. Для учебного задания обычно достаточно правильно выбрать тип графика, подписать оси, сделать читаемый заголовок и проверить, что подписи не налезают друг на друга.

## 9. Как сохранить проект

Кнопки в блоке `Проект` не экспортируют картинку. Они сохраняют или загружают рабочее состояние редактора.

- `Сохранить` — скачивает `.json` файл проекта.
- `Загрузить` — открывает ранее сохраненный `.json`.

Проектный `.json` полезен, если вы хотите продолжить работу позже или передать настройку преподавателю. Внутри сохраняются данные CSV и оформление.

## 10. Как экспортировать готовую визуализацию

На сайте нет экспорта в PDF. В блоке `Экспорт` доступны только:

- `PNG 2×`;
- `PNG 4×`;
- `SVG`.

### Когда выбирать PNG 2×

Выбирайте `PNG 2×`, если нужен обычный растровый файл для сдачи, презентации или вставки в документ.

### Когда выбирать PNG 4×

Выбирайте `PNG 4×`, если картинку нужно вставить крупно или сохранить с повышенной четкостью.

Файл получится тяжелее, чем `PNG 2×`.

### Когда выбирать SVG

Выбирайте `SVG`, если нужен редактируемый векторный файл. Его можно открыть в Figma, Illustrator, Inkscape или другом редакторе векторной графики.

SVG особенно полезен, если после экспорта нужно вручную поправить подписи, цвета или верстку.

## 11. Как назвать итоговые файлы

Используйте понятные имена. Например:

```text
01_bar_croissants.png
07_line_elevator_sleepiness.png
15_stacked_budget.svg
16_line_lectures.png
```

Удобная схема:

```text
номерзадания_типграфика_краткаятема.формат
```

Не используйте имена вроде:

```text
final.png
final_final.png
new_chart_3.png
```

## 12. Проверка перед экспортом

Перед экспортом проверьте график по чек-листу:

- выбран правильный тип диаграммы;
- `Ось X / категория` и `Ось Y / значение` не перепутаны;
- если в таблице есть группы, выбран правильный `Ряд / серия (цвет)`;
- заголовок объясняет, что показано;
- подписи осей понятны;
- единицы измерения указаны, если они есть;
- временные категории идут в правильном порядке;
- легенда есть, если используются цвета серий;
- подписи не перекрывают друг друга;
- график отвечает на вопрос из `technical_brief.docx`.

## 13. Частые ошибки

### Данные загрузились, но график странный

Проверьте сопоставление полей. Чаще всего проблема в том, что текстовый столбец попал в `Ось Y / значение`, а числовой — в `Ось X / категория`.

### Все значения выглядят одинаково или не считаются числами

Проверьте `Дес. разделитель`. Для файлов из `Tasks` обычно нужна `Точка (1.25)`.

### Таблица не разделилась на столбцы

Проверьте `Разделитель полей`. Для файлов из `Tasks` обычно нужна `Запятая (,)`.

### На графике слишком много цветов

Проверьте поле `Ряд / серия (цвет)`. Если серии не нужны, выберите `— нет —`.

### Подписи категорий не помещаются

Попробуйте одно из решений:

- выбрать `Линейчатая` вместо `Столбчатая`;
- увеличить ширину файла в блоке `Размер`;
- повернуть или проредить подписи оси на правой панели;
- сократить слишком длинные названия.

### Нужен PDF

Сайт не экспортирует визуализации в PDF. Экспортируйте `PNG` или `SVG`. Если преподавателю нужен PDF, вставьте экспортированную картинку в документ или презентацию и сохраните уже этот документ как PDF.

## 14. Быстрый алгоритм

1. Откройте `technical_brief.docx`.
2. Откройте сайт `datavizru.github.io`.
3. Включите русский интерфейс, если нужно.
4. В блоке `Данные` нажмите `Загрузить CSV…`.
5. Выберите `data.csv` из папки задания.
6. Проверьте `Ось X / категория`, `Ось Y / значение` и `Ряд / серия (цвет)`.
7. Выберите тип диаграммы.
8. Заполните заголовок, подзаголовок и подписи осей.
9. Настройте размер, цвета и подписи, если это нужно.
10. Проверьте читаемость.
11. Экспортируйте `PNG 2×`, `PNG 4×` или `SVG`.
12. При необходимости сохраните проект через `Сохранить`, чтобы получить `.json` и продолжить работу позже.

Главная цель — не просто получить красивую картинку, а сделать данные понятными. Если после просмотра графика сразу ясно, что сравнивается и какой вывод можно сделать, визуализация работает.
